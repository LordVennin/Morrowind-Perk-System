Advanced World Map ver 1.5.3

Description:

This mod adds an interactive map (default key: N) with browsing of locations, search, fast travel, notes,
and the ability to control layer visibility and the map size. The map can show either all locations
or only those you have discovered. In the mod settings you can change the keybinding for the map,
adjust marker size and color, configure fast travel, and more. On first run the mod opens a settings menu
where you can set the main options.

More info at https://www.nexusmods.com/morrowind/mods/57881


Installation:

    - Extract the archive contents into the game's "Data Files" folder, or another folder
	and add it via the OpenMW Launcher "Data Directories".
    - Download and extract the contents of the local map textures archive (from the mod's optional files) into the game's "Data Files" folder
	or another folder and add that folder in "Data Directories". For the game without Tamriel Rebuilt use
	the "Local map Textures for base game"; for TR, use "Local map Textures for TR PC SHotN".
