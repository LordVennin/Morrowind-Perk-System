# ErnExamplePerkPack

This folder contains a minimal plugin-pack layout for `SkillPerkSystem`:

- `perks/longblade.lua` - skill perk registration file.
- `effects/ern_example_longblade_precision_effect.lua` - effect handlers in a separate file.
- `skillperk_manifest.lua` - optional manifest that can register content and list modules.

These files are examples for mod authors.
